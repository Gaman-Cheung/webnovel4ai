# 故事织线 · 小说大纲 H5 原型

这是一个纯前端、无构建依赖的单页原型。直接打开 `index.html` 即可使用。

- 输入故事想法、时间、地点、类型与人物
- 点击“生成初始大纲”根据当前故事想法、地点和人物生成一版起始章节结构；已手动编辑的章节不会被覆盖
- 可添加人物、章节节点、切换结构视图
- 草稿保存在当前浏览器的 `localStorage`
- “导出 AI 提示词”复制完整 Markdown；“下载 Markdown”生成本地文件

文件说明：

- `index.html`：页面结构与中文界面
- `styles.css`：响应式视觉样式，桌面与移动端均可用
- `app.js`：交互、草稿保存、生成预览与导出逻辑

新增编辑能力：写作提示、人物双向同步、人物/时间线/事件/章节编辑、故事事实增删改，以及包含可选正文片段的完整 AI Markdown 预览与导出。

章节现在包含：当前编辑选中状态、草稿/待确认/已确定状态、重要标签（蓝色）、辅助标签（白色）；工作台会跟随当前章节，预览与 Markdown 导出会带上完整结构。

工作台显示当前选中章节及相邻章节；章节状态可切换并保存；章节编辑区将蓝色重要标签与白色辅助标签分开；总览/章节均可直接编辑。

故事地图是章节的结构视图：每个章节对应一个节点，不会凭空创建重复节点。主线/支线标签跟随章节卡片显示，并在章节编辑中设置；支线章节可以选择归属的主线章节，章节列表会将它们收进可展开的支线组。地图支持节点拖动、缩放、平移、定位当前章节；关系线旁有直接删除按钮，已建立的关系区默认收起，展开后支持搜索和删除。新增章节请从章节或地图的“添加章节”进入。

时间线是事件实际发生时间的视图，与章节的叙事顺序分开。每个时间节点可以关联章节，并选择“故事当前之前 / 回忆或闪回 / 故事当前 / 故事当前之后”，再用排序位置决定先后；因此回忆可以回到过去，但不会改变章节编号。时间线按实际时间排序，导出时会带上对应的叙事章节。
